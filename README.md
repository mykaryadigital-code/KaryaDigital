# BukuKita — Marketplace eBook Malaysia (Frontend Demo)

## Cara jalankan dalam VS Code

1. Pastikan Node.js 20.9 atau lebih baharu dipasang.
2. Buka folder `bukukita` dalam VS Code.
3. Buka Terminal > New Terminal.
4. Jalankan:

```bash
npm install
npm run dev
```

5. Buka http://localhost:3000

## Sudah berfungsi
- Carian mengikut tajuk, penulis dan kategori
- Tapisan kategori
- Tambah / buang eBook daripada troli
- Jumlah harga dalam Ringgit Malaysia
- Paparan responsif telefon dan desktop

## Belum disambungkan
- Login, Supabase, pangkalan data sebenar
- Upload PDF dan pendaftaran penjual
- Checkout, pembayaran, pustaka pembeli dan payout

Semua judul, penulis, harga, penilaian dan promosi ialah data contoh.
